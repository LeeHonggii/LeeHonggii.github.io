"랜덤 추천 목록에도 페이지네이션 붙여주세요."

간단해 보였다. `offset`, `limit` 파라미터 받아서 쿼리에 끼워 넣으면 되는 거 아닌가. 그런데 막상 생각해보니 뭔가 이상했다.

---

`ORDER BY RAND()`는 매 쿼리 실행마다 새로운 순서를 만든다. MySQL 기준으로 이 구문은 각 행에 난수를 붙인 뒤 그걸로 정렬한다. 쿼리를 두 번 실행하면 두 번 다 다른 순서가 나온다.

```sql
-- 첫 번째 페이지 요청
SELECT * FROM template WHERE status = 'active'
ORDER BY RAND()
LIMIT 30 OFFSET 0;

-- 두 번째 페이지 요청
SELECT * FROM template WHERE status = 'active'
ORDER BY RAND()
LIMIT 30 OFFSET 30;
```

페이지네이션이 의미를 가지려면 전제가 하나 있다. **정렬 순서가 요청 간에 일관되어야 한다.** 1페이지를 본 뒤 2페이지를 요청했을 때, 데이터가 같은 순서로 늘어서 있어야 `OFFSET 30`이 31번째부터 60번째까지를 정확히 가리킨다.

`ORDER BY RAND()`는 이 전제를 깨버린다. 두 번째 요청이 들어왔을 때 DB는 순서를 다시 섞는다. 그러면 1페이지에서 봤던 항목이 2페이지 범위 안에 다시 들어올 수 있고, 반대로 어떤 항목은 두 페이지 모두에서 빠질 수 있다. **중복과 누락이 동시에 발생한다.**

```
GET /random-templates?offset=0&limit=30  → [A, B, C, D, ...]
GET /random-templates?offset=30&limit=30 → [B, E, A, F, ...]  ← B와 A가 다시 등장
```

offset이 0일 때는 문제가 없다. 어차피 전체를 섞어서 앞에서 30개를 자르는 거라 중복 여지가 없다. 문제는 offset이 1 이상일 때부터다.

---

이걸 해결하는 방법 중 하나가 **seed 고정**이다. MySQL의 `RAND()` 함수는 시드값을 받을 수 있다. 같은 시드를 넣으면 같은 순서가 나온다.

```sql
SELECT * FROM template WHERE status = 'active'
ORDER BY RAND(:seed)
LIMIT 30 OFFSET 30;
```

클라이언트가 세션 시작 시 시드를 하나 생성해서 이후 페이지 요청마다 같이 보내는 방식이다. 동일한 시드 아래에서는 매번 순서가 동일하니까 offset 기반 페이지네이션이 제대로 작동한다. 랜덤성은 "세션마다 다른 순서"로 보장하고, 한 세션 안에서는 일관된 순서를 유지한다.

단점도 있다. 시드를 클라이언트가 들고 있어야 하고, 서버는 상태를 갖지 않지만 클라이언트는 상태를 갖게 된다. API가 단순한 CRUD처럼 보이지 않는다. 그리고 클라이언트가 시드를 버리면 다음 세션에서 순서가 바뀐다 — 이건 사실 원하는 동작이긴 하다.

---

논의 끝에 최종 결정은 달랐다. 랜덤 로직은 그대로 두되, **응답 포맷만 페이지네이션 형태에 맞추는 것**으로 정리했다.

```json
{
  "totalCount": 120,
  "list": [ ... ]
}
```

실제로 이 API를 여러 페이지에 걸쳐 탐색하는 사용자가 있는지 불분명했다. 클라이언트 쪽에서 필요한 건 전체 개수와 한 번에 내려줄 목록이었고, 2페이지 3페이지를 순서대로 보는 시나리오는 아직 없었다. offset을 받아는 두지만 실질적으로는 첫 번째 페이지만 쓰는 구조다.

엄밀히 말하면 이건 페이지네이션이 아니다. 페이지네이션처럼 생긴 응답 포맷이다.

그래도 지금은 이게 맞다고 생각했다. offset 기반 랜덤 페이지네이션을 제대로 구현하려면 seed 전달 방식을 클라이언트까지 맞춰야 하는데, 그 비용을 쓸 만한 유스케이스가 아직 없다. 문제가 생기면 그때 다시 보는 편이 낫다.

다만 한 가지 찜찜한 게 있다. `totalCount`를 랜덤 API에서 반환하는 게 개념적으로 깔끔한가. 전체 템플릿 수는 맞는데, 사용자가 "120개 중에 몇 페이지를 보고 있다"고 느끼게 되는 순간 offset이 의미 있다고 기대하게 된다. 그걸 깨는 경험을 언제 마주칠지는 아직 모르겠다.
